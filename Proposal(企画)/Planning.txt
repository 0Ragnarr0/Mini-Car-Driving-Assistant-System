Mini Model Car Auto-driving Assistant System

1. Define the Operational Design Domain and the initial safety rules.
	- Only sunny weather and smooth roads.Budget Limits and Complexity to finish before deadline.
	- Define the safety distance, stop distance, confidence target, and basic pass or fail conditions.
	- Build a rule-based safety envelope first so unsafe actions can be blocked.

2. Build the sensor and data pipeline.
	- Connect the sensors and cameras.
	- Build programs to collect synchronized sensor data, timestamps, and vehicle-state data.
	- Store logs so the same scenarios can be replayed later.

3. Build the perception layer.
	- Create object-detection and distance-estimation programs from the sensor and camera data.
	- Measure detection accuracy, latency, and false detections.
	- Make sure the system can reliably detect front vehicles, people, and static obstacles.

4. Build a simulation and replay environment for deep reinforcement learning.
	- Create an environment that uses recorded data or simulation scenarios.
	- Define the observation space, action space, reward function, and termination conditions.
	- Start with simple tasks such as obstacle stopping and front-car following.

5. Train the deep reinforcement learning policy.
	- Train the model to choose throttle and brake actions.
	- Reward safe progress and smooth driving.
	- Penalize collisions, unsafe following distance, late braking, and unstable control.

6. Create the core control system.
	- Combine perception, the DRL policy, and the safety envelope.
	- Let the DRL model suggest actions, but let the safety layer override unsafe decisions.
	- Send the final output to braking, acceleration, and other control systems.

7. Run staged safety tests.
	- Start with beginner-level safety checks and evaluate stopping distance, safety distance, and response delay.
	- Move to intermediate and advanced levels only after the previous level is stable.
	- Adjust the parameters, sensors, and control timing based on test results.

8. Improve the system and expand the safety evaluation.
	- Improve the model, compute speed, and sensor quality until all baseline safety checks pass.
	- After the distance-based safety checks are stable, add avoidable and unavoidable scenario analysis.
	- Expand to more difficult scenarios only after the basic safety behavior is reliable.
